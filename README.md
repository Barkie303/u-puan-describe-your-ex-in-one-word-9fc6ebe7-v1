One word that sums up an ex: **unsubscribed**.

An ex is a subscription you finally cancelled — the newsletters stop, the spam ends, and nobody misses the renewal reminder.

## Run

```sh
npx tsx main.ts
```

Writes the verdict to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
